# Feature ideas

**Name:** RecipeMate

- **Create a recipe list** Prio 1.

    → Overview over recipes with their category, time etc.
    → Search through the recipe list based on name, time, ingredients etc. 
    For example you have mushrooms and eggplant left and want to see all recipes using that
    → LLM Chatbot helping to create recipes

- **Meal prepping:** Prio 2.

    → Create a weekly planning using the predefined recipes
    → Generate a shopping list for the week (logic for spoilable products)

- **Cook a recipe:** Prio 2.

    → User can select a recipe and cook it.
    The process is displayed with checkboxes.
    → (Optional) Gamify the cooking with time tracking and updating.
    A diagram in the recipe showing the cooking time by time

- **Recipe sharing between user groups:** (Optional)
    → Users can publish recipes in different scopes (community, family...)
    → Also gamification between users and their cooking time
